# Condo UTS — ระบบบริหารจัดการห้องชุดและผู้เช่า

ต้นแบบเว็บ (prototype) ของ **Unit and Tenant Management System** สำหรับคอนโดมิเนียม สร้างตาม Context Diagram, Functional Decomposition Diagram, DFD Level 1 และ Level 2 ของโปรเจกต์

ไฟล์เดียว `index.html` เปิดในเบราว์เซอร์ได้ทันที ไม่ต้องติดตั้งอะไร ข้อมูลเก็บใน `localStorage` ของเบราว์เซอร์

## ฟังก์ชันตาม FDD

- **ผู้ดูแลระบบ:** 1.1 จัดทำใบแจ้งหนี้, 1.3 ตรวจสอบการชำระเงิน, 3.1–3.4 ผู้อยู่อาศัย, 4.1–4.4 ห้องชุด, 5.1–5.2 สัญญาเช่า, 6.1–6.2 พัสดุ, 7.1–7.3 ประกาศ, 8.1 แดชบอร์ด, 8.2–8.4 งานซ่อมและประวัติ, 9.4 สถานะงานซ่อม, 10.1–10.2 ผู้มาติดต่อ
- **ผู้อยู่อาศัย:** 1.1 ดูใบแจ้งหนี้, 1.2 ชำระใบแจ้งหนี้, 2.1–2.2 จองสิ่งอำนวยความสะดวก, 6.3 ติดตามพัสดุ, ประกาศ, 9.1 แจ้งซ่อม
- 3.5 เข้าสู่ระบบ (login)

## ความสามารถของ UI

- ธีมมืด/สว่าง, สลับภาษาไทย/อังกฤษ
- เมนูซ้ายพับเป็นแถบไอคอน, พับกลุ่มเมนูและการ์ดได้
- การแจ้งเตือน (กระดิ่ง), ค้นหา (`/`), หน้าต่างแก้ไข/ยืนยันการลบ
- ใช้งานบนมือถือได้
